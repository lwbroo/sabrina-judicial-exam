# 司律第一試題庫練習

司法官／律師第一試歷屆選擇題練習網站。純前端靜態網頁，資料存在瀏覽器本機（localStorage），不需要伺服器或資料庫。

## 功能

- 四份考卷（0101 / 0301 / 0201 / 0202），題數與作答時間依試題檔載明的規格
- 整份模擬考、隨機抽題、單一法科練習、錯題重考
- 倒數計時、答題卡、標記待確認
- 交卷後逐題檢討，答錯自動收進錯題本
- 錯題本可依考卷／年度／狀態篩選、加筆記、標記已弄懂、匯出列印
- 多帳號切換、每日打卡紀錄
- 可拖入考選部的試題與答案 PDF 自動解析建題庫

## 檔案

| 路徑 | 用途 |
| --- | --- |
| `index.html` | 網站入口（GitHub Pages 讀這支） |
| `司律第一試練習系統.dc.html` | 設計原稿，`index.html` 由它複製而來 |
| `support.js` | 執行環境 |
| `image-slot.js` | 老師圖片放置區元件 |
| `_ds/` | 設計系統樣式 |
| `pdf/` | 114 年四份考卷的試題與標準答案 PDF |

## 本機預覽

不能直接用檔案總管點開 `index.html`（瀏覽器會擋住讀取 PDF）。請在專案資料夾開一個本機伺服器：

```bash
python3 -m http.server 8000
```

然後開 http://localhost:8000

## 更新題庫

網站內的「題庫」頁可直接拖入其他年度的試題與答案 PDF，解析後按確認匯入即可。
